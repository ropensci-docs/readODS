# readODS: Read and Write ODS Files

Read ODS (OpenDocument Spreadsheet) into R as data frame. Also support
writing data frame into ODS file.

## See also

Useful links:

- <https://docs.ropensci.org/readODS/>

- <https://github.com/ropensci/readODS>

- Report bugs at <https://github.com/ropensci/readODS/issues>
